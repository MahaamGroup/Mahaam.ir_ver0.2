# وب‌سایت رسمی گروه بین‌المللی مهام (Mahaam International Group)

این پروژه پیاده‌سازی کامل، مدرن و با استانداردهای بالای وب‌سایت رسمی **گروه بین‌المللی مهام** بر اساس مستندات مرجع Build Kit، کتابچه هویت برند، معماری اطلاعات و متون نهایی صفحات (`Page Contents`) است.

---

## ویژگی‌های کلیدی سیستم و طراحی

- **طراحی مدرن و اصیل (Anti-AI Slop & Editorial Luxury):** پیاده‌سازی مطابق با راهنمای هنر و طراحی گروه مهام؛ استفاده از رنگ‌های سازمانی سرمه‌ای عمیق (`#0C2340` و `#081525`)، سبز زیتونی سازمانی (`#6DA616`)، آبی جهت‌دهنده (`#3658B6`) و بستر عاجی آرام (`#F8F6F1`).
- **تایپوگرافی فارسی اصیل:** فونت استاندارد و خوش‌خوان وزیرمتن (`Vazirmatn`) با وزن‌های متنوع، به همراه جهت‌بندی کامل راست‌به‌چپ (RTL) و اعداد تراز‌شده فارسی.
- **معماری تصمیم‌محور (Decision Driven Architecture):**
  - **صفحه اصلی (Homepage):** همراه با سکشن‌های هیرو، مخاطبان، صورت مسئله، رویکرد چهار مرحله‌ای، نقشه سفرها، دلایل انتخاب مهام، فرم دریافت راهنما، پرسش‌های متداول و دعوت به اقدام پایانی.
  - **لایه مخاطبان (Audiences):** ۵ گروه تخصصی شامل پزشکان و سلامت، وکلا و حقوقی، مدیران ارشد، صاحبان کسب‌وکار، و متخصصان/پژوهشگران با صفحات اختصاصی.
  - **لایه مسیرها (Journeys):** ۴ مسیر راهبردی شامل کشف فرصت‌ها (Discovery)، تجربه‌های بین‌المللی (Experience)، استقرار و توسعه (Development)، و رشد و همکاری بلندمدت (Growth).
  - **موتور ارزیابی و تصمیم (Mahaam Decision Engine):** ابزار تعاملی ۵ مرحله‌ای ارزیابی شرایط، ماتریس تصمیم (Decision Matrix)، طبقه‌بندی هوشمند و اتصال به فرم دریافت ارزیابی اولیه با صدور کد پیگیری.
  - **درباره مهام و متدولوژی:** تشریح کامل هویت، چرایی شکل‌گیری، رویکرد و تعهدات اخلاق حرفه‌ای و اصالت.
  - **تجربه‌های مستند (Experiences):** روایت‌های واقعی و مستند از پزشکان، وکلا، کارآفرینان و پژوهشگران.
  - **بینش‌ها و تحلیل‌ها (Insights):** مقالات تخصصی پیرامون تصمیم‌گیری در عدم قطعیت، سیستم‌های سلامت فرامرزی، و انطباق بانکی.
  - **فرم ارتباط هوشمند (Smart Contact):** انتخاب هوشمند موضوع، اعتبارسنجی سمت کاربر، و راهنمایی گام‌به‌گام پس از ارسال.
  - **پرسش‌های متداول (FAQ):** تفکیک‌شده بر اساس موضوعات با فیلتر دسته‌بندی.
  - **اسناد حقوقی:** حریم خصوصی و محرمانگی داده‌ها، قوانین و مقررات.

## فرمان‌های اجرا و ساخت

### اجرای محیط توسعه:
```bash
npm run dev
```
سرور بر روی پورت `3000` در دسترس خواهد بود.

### ساخت نسخه نهایی تولیدی (Production Build):
```bash
npm run build
```

### بررسی تایپ‌چک و لینتینگ:
```bash
npm run lint
```
